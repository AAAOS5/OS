## 二、实验简介

操作系统原理实验以「把课上的原理动手实现一遍」为目标，围绕操作系统的几个核心机制展开：进程与线程的管理和调度、进程间的同步与互斥、死锁的避免与检测、内存与虚拟存储管理、设备与文件管理。每次实验针对其中一个主题，用编程语言模拟或实现相应的算法，并通过给定的测试用例验证结果的正确性。

每次实验结束后，在对应目录下提交源码、实验报告和运行结果截图，报告内容包括实验目的、实验环境、算法原理、实现思路、运行结果与分析、心得体会。
